# Ghost 猫 · 细化版

KuroCat 桌宠皮肤，已在 macOS 上用 KuroCat v1.5.3 验证导入。

![Ghost 猫细化版预览](preview.png)

在 KuroCat 菜单栏选择「猫咪皮肤 → 导入皮肤…」，然后选择 [Ghost-Cat-Refined.kurocat](Ghost-Cat-Refined.kurocat)。

角色形象参考二哈拆迁队大队长的 Ghost 猫。本仓库用于个人留存，原项目的分享说明未授予角色改编后的公开发布许可。 [原项目与分享说明](https://github.com/Alba0567/Ghost-cat-desktop)
